# WhichMarkDoINeed
Ein Programm das ausrechnet, welche Note man braucht um den gewünschten Schnitt zu erreichen.

## Hintergedanke
Nehmen wir mal an, man hat einen schlechten Schnitt. Dann würden sich die Meisten folgendes überlegen: "Welche Note brauche ich, um meinen Schnitt ins Genügende zu bringen". Wie z.B. für eine 4. Ich selbst war schon ein paar Mal in der Situation und musste dann mehrmals mit dem Taschenrechner ausprobieren und schauen, welche Note mich wieder auf Vordermann bringt.

Dazu nun die Idee, dass man alle Noten eingibt und am Ende angibt, welchen Schnitt man sich wünscht. Danach berechnet das Tool selbst, welche Note man braucht. Das macht das Leben sehr viel einfacher!
